# Stock Scout Project Information

## Intentions

Security Screening and Analytical Tool--transforming an existing project (Lab Scout) into one that encompasses a new domain (finance).

## Proposed Development Phases (subject to change)

### Phase 1
- Developing new schema for the database, transferring attributes and functions to align with a static security screener.

### Phase 1.5 (additive features)
- function to refresh columns in the database, namely 'market_cap' and 'latest_price', to reflect real-time data.
- function to add security with ticker alone, remaining fields populated through yfinance data.
- function to copy database information to watchlist, intended to reflect real data instead of the existing placeholder.
